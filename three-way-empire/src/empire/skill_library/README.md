# Built-in Empire skills

Each folder is one skill: `<name>/SKILL.md`, where the folder name must match `name:`.
These are read-only platform skills. Operators add more with `EMPIRE_SKILLS_DIR` or
`POST /api/v1/empire/skills`. Clients add their own with `POST /api/v1/empire/tenant/skills`.
See `docs/EMPIRE.md` (Phase 11) for the format.
